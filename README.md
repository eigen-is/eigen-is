# Eigen

Eigen is a self-hosted alternative to Google Workspace. Mail, drive, docs, sheets, slides,
calendar, contacts and chat, in one open source (MIT) server.

The name is Dutch and German for "own". You own your data because of how it is stored: mail in
plain Maildir++ that Dovecot can read, files as normal files over WebDAV, calendars over CalDAV,
documents in SQLite databases you can copy and inspect with standard tools.

Reality check: Eigen is pre-1.0 and built by one person in his spare time. The core works and
improves fast, but I would not yet trust it with data you cannot afford to lose. For hobbyists,
self-hosters and small teams comfortable with rough edges, it is ready to try.
